សន្លឹកកិច្ចការលំហាត់អនុវត្ត៖ អនុគមន៍លោការីត ថ្នាក់ទី១១ (Logarithmic Functions)

រចនាតាមលំដាប់លំដោយមេរៀនពីតូចទៅធំ ៣ ជួរឈរ លើក្រដាស A4 (KaTeX ពេញលេញ មិនបាត់បង់ text)

CHHENG CHHORVORN
គណិតវិទ្យាថ្នាក់ទី១១(សង្ខេប)
លំហាត់
អនុគមន៍លោការីត(២០២៥-២០២៦)
១. សម្រួល និងគណនាតម្លៃកន្សោមលោការីតខាងក្រោម៖
ក. $A = \\log_2 16 + \\log_3 27 - \\log_5 125$ $= 4$
ខ. $B = \\log_2 \\sqrt{8} + \\log_3 \\sqrt[3]{9}$ $= \\frac{13}{6}$
គ. $C = \\log_6 4 + \\log_6 9$ $= 2$
ឃ. $D = \\log_2 40 - \\log_2 5$ $= 3$
ង. $E = 2\\log_3 6 - \\log_3 4$ $= 2$
ច. $F = \\log_2 3 \\cdot \\log_3 4 \\cdot \\log_4 8$ $= 3$
ឆ. $G = 4^{\\log_2 5} + 9^{\\log_3 2}$ $= 29$
ជ. $H = \\ln(e^5) - \\ln\\left(\\dfrac{1}{e^2}\\right) + \\ln 1$ $= 7$
ឈ. $I = \\log_{\\frac{1}{2}} 8 + \\log_{\\frac{1}{3}} 81$ $= -7$
ញ. $J = \\dfrac{\\log 8}{\\log 4} + \\dfrac{\\log 27}{\\log 9}$ $= 3$
ដ. $K = \\log_{\\sqrt{3}} (9\\sqrt{3})$ $= 5$
ឋ. $L = e^{2\\ln 3} - e^{-\\ln 2}$ $= 8.5$
២. រកដែនកំណត់នៃអនុគមន៍លោការីតខាងក្រោម៖
ក. $f(x) = \\log_2(3x - 6)$ ($x > 2$)
ខ. $g(x) = \\log_5(x^2 - 9)$ ($|x| > 3$)
គ. $h(x) = \\ln\\left(\\dfrac{x+1}{x-2}\\right)$ ($x<-1 \\lor x>2$)
ឃ. $k(x) = \\log_3(4 - x^2)$ ($-2 < x < 2$)
ង. $p(x) = \\log_{(x-1)}(x+3)$ ($x>1, x \\ne 2$)
ច. $q(x) = \\sqrt{\\log_2(x - 1)}$ ($x \\ge 2$)
៣. ដោះស្រាយសមីការលោការីតខាងក្រោម៖
ក. $\\log_2(x - 3) = 4$ ($x = 19$)
ខ. $\\log_3(2x + 1) = 2$ ($x = 4$)
គ. $\\log_5(x^2 - 4x) = 1$ ($x = -1; 5$)
ឃ. $\\log_2(x+1) + \\log_2(x-1) = 3$ ($x = 3$)
ង. $\\log_3(x+2) - \\log_3(x-1) = 1$ ($x = 2.5$)
ច. $\\log_4(x + 3) = \\log_4(2x - 1)$ ($x = 4$)
ឆ. $\\log_2(x+2) + \\log_2(x+4) = 3$ ($x = 0$)
ជ. $\\ln(2x - 1) = 0$ ($x = 1$)
ឈ. $\\log(x - 2) + \\log(x + 1) = 1$ ($x = 4$)
ញ. $\\log_3(x^2 - 6) = \\log_3 x$ ($x = 3$)
ដ. $\\log_2(x-5) + \\log_2(x+2) = 3$ ($x = 6$)
ឋ. $\\log_{\\frac{1}{2}}(3x - 1) = -2$ ($x = 5/3$)
ឌ. $\\log_2^2 x - 3\\log_2 x + 2 = 0$ ($x = 2; 4$)
ឍ. $\\log_3^2 x - 4\\log_3 x + 3 = 0$ ($x = 3; 27$)
ណ. $\\log_2 x + \\log_x 2 = 2$ ($x = 2$)
ត. $\\log_2 x + 4\\log_x 2 = 5$ ($x = 2; 16$)
ថ. $x^{\\log_3 x} = 81$ ($x = 9; 1/9$)
ទ. $\\ln^2 x - \\ln(x^3) + 2 = 0$ ($x = e; e^2$)
៤. ដោះស្រាយវិសមីការលោការីតខាងក្រោម៖
ក. $\\log_2(x - 1) < 3$ ($1 < x < 9$)
ខ. $\\log_3(2x + 1) \\ge 2$ ($x \\ge 4$)
គ. $\\log_{\\frac{1}{2}}(x - 2) > -1$ ($2 < x < 4$)
ឃ. $\\log_{0.5}(2x - 3) \\le \\log_{0.5}(x + 1)$ ($x \\ge 4$)
ង. $\\log_2(x+1) + \\log_2(x-1) \\le 3$ ($1 < x \\le 3$)
ច. $\\log_2(x^2 - 2x) \\le 3$ ($[-2,0) \\cup (2,4]$)
ឆ. $\\log_2^2 x - 3\\log_2 x + 2 < 0$ ($2 < x < 4$)
ជ. $\\log_{\\frac{1}{3}}(x^2 - 1) \\ge -1$ ($[-2,-1) \\cup (1,2]$)
ឈ. $\\ln(x^2 - 5x + 7) \\le 0$ ($2 \\le x \\le 3$)
ញ. $\\log(x - 1) + \\log(x + 2) < 1$ ($1 < x < 3$)
ដ. $\\log_2(3x - 2) > \\log_2(x + 4)$ ($x > 3$)
ឋ. $\\log_{\\frac{1}{4}}(2x + 3) > -1$ ($-1.5 < x < 0.5$)
៥. បញ្ហាអនុវត្តជាក់ស្តែងក្នុងជីវភាព៖
១. សំឡេង (dB)៖ $\\beta = 10\\log_{10}(I/I_0)$ ដោយ $I_0 = 10^{-12}\\text{ W/m}^2$។ រក $\\beta$ បើ $I = 10^{-1}\\text{ W/m}^2$។ ($\\beta = 110\\text{ dB}$)
២. គីមីវិទ្យា (pH)៖ $\\text{pH} = -\\log_{10}[H^+]$។ រក $\\text{pH}$ បើសូលុយស្យុងមាន $[H^+] = 10^{-3}\\text{ M}$។ ($\\text{pH} = 3$)
៣. រញ្ជួយដី (Richter)៖ $M = \\frac{2}{3}\\log_{10}(E/E_0)$។ ប្រៀបធៀបថាមពល $E$ នៃកម្រិត $M=7$ ធៀបនឹង $M=5$។ ($E_7/E_5 = 1,000\\text{ ដង}$)

គណិតវិទ្យាថ្នាក់ទី១១(សង្ខេប)
លំហាត់
អនុគមន៍អ៊ិចស្ប៉ូណង់ស្យែល(២០២៥-២០២៦)
១. សម្រួល និងគណនាតម្លៃកន្សោមខាងក្រោម៖
ក. $A = 2^3 \cdot 2^5 \cdot 2^{-4}$ $= 16$
ខ. $B = \dfrac{3^4 \cdot 9^2}{27^2}$ $= 9$
គ. $C = \dfrac{5^{x+2} - 5^x}{5^{x-1}}$ $= 120$
ឃ. $D = \left(\dfrac{1}{2}\right)^{-3} + \left(\dfrac{2}{3}\right)^{-2} - 16^{0.25}$ $= 8.25$
ង. $E = \sqrt[3]{2^6} \cdot \sqrt{4^3}$ $= 32$
ច. $F = \dfrac{a^{2/3} \cdot b^{-1/2}}{(a^4 b^{-3})^{1/6}}$ $= 1$
ឆ. $G = \dfrac{2^{n+4} - 2 \cdot 2^n}{2 \cdot 2^{n+3}}$ $= \frac{7}{8}$
ជ. $H = \dfrac{e^{3x} + e^{-3x}}{e^x + e^{-x}}$ $= e^{2x} + e^{-2x} - 1$
ឈ. $I = (e^x + 1)^2 - (e^x - 1)^2$ $= 4e^x$
ញ. $J = \dfrac{e^{2x} - 1}{e^x - 1}$ $= e^x + 1$
ដ. $K = \sqrt{e^{4x} + 2e^{2x} + 1}$ $= e^{2x} + 1$
ឋ. $L = \dfrac{e^x + e^{2x} + e^{3x}}{e^{-x} + e^{-2x} + e^{-3x}}$ $= e^{4x}$
២. ដោះស្រាយសមីការអ៊ិចស្ប៉ូណង់ស្យែលខាងក្រោម៖
ក. $2^{x-1} = 16$ ($x = 5$)
ខ. $3^{2x+1} = 27$ ($x = 1$)
គ. $5^{x^2 - 3x} = 5^4$ ($x = 4; -1$)
ឃ. $4^x = \dfrac{1}{64}$ ($x = -3$)
ង. $\left(\dfrac{2}{3}\right)^x = \dfrac{27}{8}$ ($x = -3$)
ច. $9^{x-2} = 27^{x+1}$ ($x = -7$)
ឆ. $2^{x^2 - 5x + 6} = 1$ ($x = 2; 3$)
ជ. $e^{2x-3} = 1$ ($x = 1.5$)
ឈ. $4 \cdot 2^{2x} = 2^{5x-4}$ ($x = 2$)
ញ. $2^{x+1} + 2^x = 24$ ($x = 3$)
ដ. $3^{x+1} - 2 \cdot 3^{x-1} = 63$ ($x = 3$)
ឋ. $5^{x+1} + 5^{x-1} = 26$ ($x = 1$)
ឌ. $4^x - 3 \cdot 2^x + 2 = 0$ ($x = 0; 1$)
ឍ. $9^x - 4 \cdot 3^x + 3 = 0$ ($x = 0; 1$)
ណ. $25^x - 6 \cdot 5^x + 5 = 0$ ($x = 0; 1$)
ត. $4^x - 5 \cdot 2^x + 4 = 0$ ($x = 0; 2$)
ថ. $9^x - 10 \cdot 3^x + 9 = 0$ ($x = 0; 2$)
ទ. $16^x - 5 \cdot 4^x + 4 = 0$ ($x = 0; 1$)
ធ. $2^{2x+1} - 9 \cdot 2^x + 4 = 0$ ($x = -1; 2$)
ន. $3^{2x+1} - 10 \cdot 3^x + 3 = 0$ ($x = -1; 1$)
ប. $5^{2x+1} - 26 \cdot 5^x + 5 = 0$ ($x = -1; 1$)
ផ. $e^{2x} - 4e^x + 3 = 0$ ($x = 0; \ln 3$)
ព. $2^x + 2^{2-x} = 5$ ($x = 0; 2$)
ភ. $3 \cdot 4^x - 5 \cdot 6^x + 2 \cdot 9^x = 0$ ($x = 0; 1$)
៣. ដោះស្រាយវិសមីការអ៊ិចស្ប៉ូណង់ស្យែលខាងក្រោម៖
ក. $2^{x+3} > 8$ ($x > 0$)
ខ. $3^{2x-1} \le 27$ ($x \le 2$)
គ. $5^{x^2 - 4} \ge 1$ ($|x| \ge 2$)
ឃ. $\left(\dfrac{1}{2}\right)^{2x-1} > \left(\dfrac{1}{2}\right)^{x+2}$ ($x < 3$)
ង. $\left(\dfrac{1}{3}\right)^{x^2 - 3} \le \dfrac{1}{9}$ ($|x| \ge \sqrt{5}$)
ច. $\left(\dfrac{2}{5}\right)^{3x-2} > \left(\dfrac{5}{2}\right)^{x-4}$ ($x < 1.5$)
ឆ. $4^x - 3 \cdot 2^x + 2 < 0$ ($0 < x < 1$)
ជ. $9^x - 4 \cdot 3^x + 3 \ge 0$ ($x \le 0 \lor x \ge 1$)
ឈ. $25^x - 6 \cdot 5^x + 5 \le 0$ ($0 \le x \le 1$)
ញ. $e^{2x} - 3e^x + 2 > 0$ ($x < 0 \lor x > \ln 2$)
ដ. $2^{x+2} + 2^{x+1} + 2^x \le 28$ ($x \le 2$)
ឋ. $4^x - 5 \cdot 2^x + 4 \le 0$ ($0 \le x \le 2$)
