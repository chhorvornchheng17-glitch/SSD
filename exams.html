វិញ្ញាសាគំរូប្រឡងបាក់ឌុប គណិតវិទ្យា (ថ្នាក់វិទ្យាសាស្ត្រ)

📅 សម័យប្រឡង៖ ២០២៦ ⏱️ រយៈពេល៖ ១៥០ នាទី 💯 ពិន្ទុពេញ៖ ១២៥ ពិន្ទុ
I. ចំនួនកុំផ្លិច (១៥ ពិន្ទុ)
១. ដោះស្រាយសមីការក្នុង $\mathbb{C}$៖ $z^2 - 4z + 8 = 0$។
២. តាង $z_1, z_2$ ជាឫសទាំងពីរនៃសមីការខាងលើ។ សរសេរ $z_1, z_2$ ជាទម្រង់ត្រីកោណមាត្រ រួចគណនា $T = z_1^6 + z_2^6$។
✅ ការបែងចែកពិន្ទុ (Mark Scheme)៖
  • គណនា $\Delta' = (-2)^2 - 8 = -4 = (2i)^2$: ៥ ពិន្ទុ
  • រកឫស $z_1 = 2 + 2i, z_2 = 2 - 2i$: ៥ ពិន្ទុ
  • ទម្រង់ត្រីកោណមាត្រ $z_{1,2} = 2\sqrt{2}(\cos(\pm \pi/4) + i\sin(\pm \pi/4))$ និងទាញបាន $T = -1024$: ៥ ពិន្ទុ
II. ប្រូបាប (១៥ ពិន្ទុ)
ក្នុងថង់មួយមានបាល់ពណ៌ក្រហម ៥ បាល់ពណ៌ខៀវ ៤ និងបាល់ពណ៌លឿង ៣។ គេចាប់យកបាល់ ៣ ព្រមគ្នាដោយចៃដន្យ។
គណនាប្រូបាបនៃបាតុភូតខាងក្រោម៖
ក. A: «ចាប់បានបាល់ទាំង ៣ មានពណ៌ខុសៗគ្នា»
ខ. B: «ចាប់បានបាល់យ៉ាងតិចមានពណ៌ក្រហមមួយ»
✅ ការបែងចែកពិន្ទុ (Mark Scheme)៖
  • ចំនួនករណីអាច $n(S) = C_{12}^3 = 220$: ៣ ពិន្ទុ
  • $P(A) = \frac{C_5^1 \times C_4^1 \times C_3^1}{220} = \frac{60}{220} = \frac{3}{11}$: ៦ ពិន្ទុ
  • $P(B) = 1 - P(\bar{B}) = 1 - \frac{C_7^3}{220} = 1 - \frac{35}{220} = \frac{37}{44}$: ៦ ពិន្ទុ
III. ធរណីមាត្រក្នុងលំហ (២០ ពិន្ទុ)
ក្នុងតម្រុយអរតូណរមេ $(O, \vec{i}, \vec{j}, \vec{k})$ គេឱ្យចំណុច $A(1, 0, 2), B(2, -1, 4), C(0, 3, 1)$ និង $D(3, 1, 2)$។
១. គណនាផលគុណវ៉ិចទ័រ $\vec{AB} \times \vec{AC}$ រួចទាញរកក្រឡាផ្ទៃត្រីកោណ $ABC$។
២. សរសេរសមីការប្លង់ $(P)$ កាត់តាមចំណុច $A, B, C$។
៣. គណនាចម្ងាយពីចំណុច $D$ ទៅប្លង់ $(P)$។
✅ ការបែងចែកពិន្ទុ (Mark Scheme)៖
  • $\vec{AB} = (1, -1, 2), \vec{AC} = (-1, 3, -1) \implies \vec{AB} \times \vec{AC} = (-5, -1, 2)$: ៧ ពិន្ទុ
  • សមីការប្លង់ $(P): -5(x-1) - (y-0) + 2(z-2) = 0 \implies 5x + y - 2z - 1 = 0$: ៧ ពិន្ទុ
  • ចម្ងាយ $d(D, P) = \frac{|5(3) + 1 - 2(2) - 1|}{\sqrt{25+1+4}} = \frac{11}{\sqrt{30}}$: ៦ ពិន្ទុ
IV. អាំងតេក្រាល (២០ ពិន្ទុ)
១. គណនាអាំងតេក្រាល $I = \int_0^1 (2x + 1) e^x dx$ ដោយប្រើអាំងតេក្រាលដោយផ្នែក។
២. រកក្រឡាផ្ទៃដែនប្លង់ខណ្ឌដោយខ្សែកោង $y = x^2 - 4x + 3$ និងអ័ក្សអាប់ស៊ីស $Ox$ លើចន្លោះ $[1, 3]$។
✅ ការបែងចែកពិន្ទុ (Mark Scheme)៖
  • អាំងតេក្រាលដោយផ្នែក $u = 2x+1, dv = e^x dx \implies I = e + 1$: ១០ ពិន្ទុ
  • ក្រឡាផ្ទៃ $S = -\int_1^3 (x^2 - 4x + 3)dx = \frac{4}{3}$ ឯកតាផ្ទៃ: ១០ ពិន្ទុ
V. សិក្សាអនុគមន៍ និងសង់ក្រាប (៥៥ ពិន្ទុ)
គេឱ្យអនុគមន៍ $f(x) = \frac{x^2 - 3x + 6}{x - 2}$ តាងក្រាបដោយ $(C)$។
១. រកដែនកំណត់នៃអនុគមន៍ $f$។
២. បង្ហាញថា $f(x) = x - 1 + \frac{4}{x - 2}$។
៣. គណនាលីមីតត្រង់ចុងដែនកំណត់ និងទាញរកសមីការបន្ទាត់អាស៊ីមតូតឈរ និងអាស៊ីមតូតទ្រេតនៃ $(C)$។
៤. គណនាដេរីវេ $f'(x)$ សិក្សាសញ្ញា និងគូសតារាងអថេរភាព។
៥. បង្ហាញថាចំណុច $I(2, 1)$ ជាផ្ចិតឆ្លុះនៃក្រាប $(C)$។
៦. សង់បន្ទាត់អាស៊ីមតូត និងក្រាប $(C)$ ក្នុងតម្រុយអរតូណរមេ។
✅ ការបែងចែកពិន្ទុ (Mark Scheme)៖
  • ដែនកំណត់ $D = \mathbb{R} \setminus \{2\}$: ៥ ពិន្ទុ
  • ទម្រង់កាណូនិច $f(x) = x - 1 + \frac{4}{x-2}$: ៥ ពិន្ទុ
  • លីមីត និងអាស៊ីមតូតឈរ $x=2$, ទ្រេត $y=x-1$: ១០ ពិន្ទុ
  • ដេរីវេ $f'(x) = \frac{x(x-4)}{(x-2)^2}$ និងតារាងអថេរភាព: ១៥ ពិន្ទុ
  • ផ្ចិតឆ្លុះ $I(2, 1)$ តាមរូបមន្ត $f(4-x) + f(x) = 2$: ៥ ពិន្ទុ
  • សង់ក្រាប $(C)$ ស្អាត ត្រឹមត្រូវ មានបន្ទាត់អាស៊ីមតូត៖ ១៥ ពិន្ទុ
