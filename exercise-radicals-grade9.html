កម្រងលំហាត់អនុវត្ត៖ រកឫសការេនៃមួយចំនួន
ថ្នាក់ទី៩ (បែងចែកជា ៣ កម្រិត៖ ស្រាល មធ្យម និងខ្ពស់)

ប្រជុំលំហាត់អនុវត្តគ្រប់ជ្រុងជ្រោយស្តីពី «ការរកឫសការេនៃមួយចំនួន» ស្របតាមកម្មវិធីសិក្សាគណិតវិទ្យាថ្នាក់ទី៩ របស់ក្រសួងអប់រំ យុវជន និងកីឡា។ រៀបចំជា ២០ លំហាត់ធំ ៨០ សំណួរ ចែកតាមលំដាប់លំដោយគរុកោសល្យ៖ កម្រិតស្រាល (៧ លំហាត់), កម្រិតមធ្យម (៧ លំហាត់) និងកម្រិតខ្ពស់ (៦ លំហាត់) ជាមួយចម្លើយសង្ខេបផ្ទៀងផ្ទាត់ និងការនាំចេញជា Word/A4 Print។

២០ លំហាត់ពេញលេញ ចែកជា ៣ ផ្នែកតាមកម្រិតសមត្ថភាព (ស្រាល ៧, មធ្យម ៧, ខ្ពស់ ៦) លើក្រដាស A4

សន្លឹកកិច្ចការគំរូគរុកោសល្យ ថ្នាក់ទី៩ (ក្រសួងអប់រំ យុវជន និងកីឡា)

២០ លំហាត់ពេញលេញ

រៀបចំដោយអនុវត្តតាមទ្រឹស្តីបទផលគុណ ផលចែក ការេពេញលេញ សនិទានកម្មភាគបែង និងការដោះស្រាយសមីការរ៉ាឌីកាល់។ ចុចប៊ូតុង «👁️ បង្ហាញចម្លើយ» ដើម្បីផ្ទៀងផ្ទាត់លទ្ធផលភ្លាមៗ ឬបោះពុម្ពជាក្រដាសកិច្ចការសម្រាប់សិស្ស។

រកឫសការេនៃមួយចំនួន (២០២៥-២០២៦)
រៀបរៀងដោយ៖ អ្នកគ្រូ ឆេង ឆវ័ន្ត (CVN Math)
កម្រិតសិក្សា៖ ថ្នាក់ទី៩ (ជំពូកទី ១)
ចំនួនលំហាត់៖ ២០ លំហាត់ធំ (៨០ សំណួរ)
🟢 ផ្នែកទី ១៖ កម្រិតស្រាល (Basic Level — ៧ លំហាត់ដំបូង)
លំហាត់ទី ១. គណនាឫសការេនៃចំនួនការេពេញលេញខាងក្រោម៖ ស្រាល • ៤ សំណួរ
ក. $\sqrt{49}$ $= 7$
ខ. $\sqrt{81}$ $= 9$
គ. $\sqrt{144}$ $= 12$
ឃ. $\sqrt{225}$ $= 15$
លំហាត់ទី ២. រកឫសការេទាំងអស់ (ទាំងវិជ្ជមាន និងអវិជ្ជមាន) នៃចំនួនខាងក្រោម៖ ស្រាល • ៤ សំណួរ
ក. ចំនួន $64$ $\to \pm 8$
ខ. ចំនួន $100$ $\to \pm 10$
គ. ចំនួន $\dfrac{4}{9}$ $\to \pm \dfrac{2}{3}$
ឃ. ចំនួន $0.36$ $\to \pm 0.6$
លំហាត់ទី ៣. គណនាឫសការេនៃចំនួនទសភាគខាងក្រោម៖ ស្រាល • ៤ សំណួរ
ក. $\sqrt{0.04}$ $= 0.2$
ខ. $\sqrt{0.25}$ $= 0.5$
គ. $\sqrt{1.21}$ $= 1.1$
ឃ. $\sqrt{0.0081}$ $= 0.09$
លំហាត់ទី ៤. គណនាឫសការេនៃប្រភាគ និងចំនួនចម្រុះខាងក្រោម៖ ស្រាល • ៤ សំណួរ
ក. $\sqrt{\dfrac{25}{36}}$ $= \dfrac{5}{6}$
ខ. $\sqrt{\dfrac{49}{100}}$ $= \dfrac{7}{10}$
គ. $\sqrt{\dfrac{121}{169}}$ $= \dfrac{11}{13}$
ឃ. $\sqrt{1\dfrac{7}{9}}$ $= \sqrt{\dfrac{16}{9}} = \dfrac{4}{3}$
លំហាត់ទី ៥. គណនាតម្លៃនៃកន្សោមប្រមាណវិធីសាមញ្ញ៖ ស្រាល • ៤ សំណួរ
ក. $A = \sqrt{9} + \sqrt{16}$ $= 3 + 4 = 7$
ខ. $B = \sqrt{100} - \sqrt{36}$ $= 10 - 6 = 4$
គ. $C = 3\sqrt{25} - 2\sqrt{4}$ $= 15 - 4 = 11$
ឃ. $D = \dfrac{\sqrt{64}}{\sqrt{16}}$ $= \dfrac{8}{4} = 2$
លំហាត់ទី ៦. រកតម្លៃ $x$ ពីសមីការសាមញ្ញរាង $x^2 = a$៖ ស្រាល • ៤ សំណួរ
ក. $x^2 = 36$ $\to x = \pm 6$
ខ. $x^2 = 121$ $\to x = \pm 11$
គ. $x^2 = \dfrac{16}{49}$ $\to x = \pm \dfrac{4}{7}$
ឃ. $x^2 - 81 = 0$ $\to x = \pm 9$
លំហាត់ទី ៧. ប្រៀបធៀបតម្លៃនៃចំនួន (ដោយមិនប្រើម៉ាស៊ីនគិតលេខ)៖ ស្រាល • ៤ សំណួរ
ក. $\sqrt{25}$ និង $6$ $\to \sqrt{25} < 6$ ($5 < 6$)
ខ. $\sqrt{48}$ និង $7$ $\to \sqrt{48} < 7$ ($48 < 49$)
គ. $2\sqrt{3}$ និង $\sqrt{11}$ $\to 2\sqrt{3} > \sqrt{11}$ ($\sqrt{12} > \sqrt{11}$)
ឃ. $\sqrt{0.5}$ និង $0.5$ $\to \sqrt{0.5} > 0.5$ ($0.5 > 0.25$)
🟡 ផ្នែកទី ២៖ កម្រិតមធ្យម (Medium Level — ៧ លំហាត់កណ្តាល)
លំហាត់ទី ៨. បញ្ចេញកត្តាពីក្រោមរ៉ាឌីកាល់ (សម្រួលរ៉ាឌីកាល់ទៅជាទម្រង់សាមញ្ញ)៖ មធ្យម • ៤ សំណួរ
ក. $\sqrt{12}$ $= \sqrt{4 \times 3} = 2\sqrt{3}$
ខ. $\sqrt{50}$ $= \sqrt{25 \times 2} = 5\sqrt{2}$
គ. $\sqrt{72}$ $= \sqrt{36 \times 2} = 6\sqrt{2}$
ឃ. $\sqrt{180}$ $= \sqrt{36 \times 5} = 6\sqrt{5}$
លំហាត់ទី ៩. បញ្ចូលកត្តាទៅក្នុងរ៉ាឌីកាល់ ($a\sqrt{b} = \sqrt{a^2 b}$)៖ មធ្យម • ៤ សំណួរ
ក. $3\sqrt{2}$ $= \sqrt{9 \times 2} = \sqrt{18}$
ខ. $5\sqrt{3}$ $= \sqrt{25 \times 3} = \sqrt{75}$
គ. $2\sqrt{7}$ $= \sqrt{4 \times 7} = \sqrt{28}$
ឃ. $\dfrac{1}{2}\sqrt{20}$ $= \sqrt{\dfrac{20}{4}} = \sqrt{5}$
លំហាត់ទី ១០. គណនាផលគុណ និងផលចែករ៉ាឌីកាល់៖ មធ្យម • ៤ សំណួរ
ក. $\sqrt{8} \times \sqrt{2}$ $= \sqrt{16} = 4$
ខ. $\sqrt{3} \times \sqrt{27}$ $= \sqrt{81} = 9$
គ. $\dfrac{\sqrt{75}}{\sqrt{3}}$ $= \sqrt{\dfrac{75}{3}} = \sqrt{25} = 5$
ឃ. $\sqrt{32}\times\sqrt{2} - \dfrac{\sqrt{98}}{\sqrt{2}}$ $= 8 - 7 = 1$
លំហាត់ទី ១១. គណនាផលបូក និងផលដករ៉ាឌីកាល់ដូចគ្នា (Like Radicals)៖ មធ្យម • ៤ សំណួរ
ក. $2\sqrt{5} + 6\sqrt{5} - 3\sqrt{5}$ $= 5\sqrt{5}$
ខ. $\sqrt{18} + \sqrt{50} - \sqrt{8}$ $= 3\sqrt{2} + 5\sqrt{2} - 2\sqrt{2} = 6\sqrt{2}$
គ. $3\sqrt{20} - \sqrt{45} + 2\sqrt{80}$ $= 6\sqrt{5} - 3\sqrt{5} + 8\sqrt{5} = 11\sqrt{5}$
ឃ. $\sqrt{27} - 2\sqrt{12} + \sqrt{75}$ $= 3\sqrt{3} - 4\sqrt{3} + 5\sqrt{3} = 4\sqrt{3}$
លំហាត់ទី ១២. ពង្រាយ និងគណនាកន្សោមរ៉ាឌីកាល់ដោយប្រើរូបមន្តស្វ័យគុណ៖ មធ្យម • ៤ សំណួរ
ក. $(\sqrt{3} + \sqrt{2})^2$ $= 3 + 2\sqrt{6} + 2 = 5 + 2\sqrt{6}$
ខ. $(\sqrt{5} - 1)^2$ $= 5 - 2\sqrt{5} + 1 = 6 - 2\sqrt{5}$
គ. $(\sqrt{7} + \sqrt{3})(\sqrt{7} - \sqrt{3})$ $= 7 - 3 = 4$
ឃ. $(2\sqrt{3} - \sqrt{5})(2\sqrt{3} + \sqrt{5})$ $= 12 - 5 = 7$
លំហាត់ទី ១៣. សនិទានកម្មភាគបែង (បំបាត់រ៉ាឌីកាល់ពីភាគបែង)៖ មធ្យម • ៤ សំណួរ
ក. $\dfrac{6}{\sqrt{3}}$ $= \dfrac{6\sqrt{3}}{3} = 2\sqrt{3}$
ខ. $\dfrac{10}{\sqrt{5}}$ $= \dfrac{10\sqrt{5}}{5} = 2\sqrt{5}$
គ. $\dfrac{4}{\sqrt{7} - \sqrt{3}}$ $= \dfrac{4(\sqrt{7}+\sqrt{3})}{4} = \sqrt{7}+\sqrt{3}$
ឃ. $\dfrac{\sqrt{2}}{\sqrt{3} + 1}$ $= \dfrac{\sqrt{6} - \sqrt{2}}{2}$
លំហាត់ទី ១៤. ដោះស្រាយសមីការមានរ៉ាឌីកាល់៖ មធ្យម • ៤ សំណួរ
ក. $2x^2 - 50 = 0$ $\to x = \pm 5$
ខ. $(x - 1)^2 = 25$ $\to x = 6$ ឬ $x = -4$
គ. $\sqrt{x} = 5$ $\to x = 25$
ឃ. $\sqrt{2x + 1} = 3$ $\to 2x+1 = 9 \implies x = 4$
🔴 ផ្នែកទី ៣៖ កម្រិតខ្ពស់ (Advanced Level — ៦ លំហាត់ចុងក្រោយ)
លំហាត់ទី ១៥. សម្រួលកន្សោមរ៉ាឌីកាល់ស្មុគស្មាញរាង $\sqrt{A \pm 2\sqrt{B}}$ (ឫសក្នុងឫស)៖ ខ្ពស់ • ៤ សំណួរ
ក. $\sqrt{7 + 2\sqrt{10}}$ $= \sqrt{(\sqrt{5}+\sqrt{2})^2} = \sqrt{5} + \sqrt{2}$
ខ. $\sqrt{8 - 2\sqrt{15}}$ $= \sqrt{(\sqrt{5}-\sqrt{3})^2} = \sqrt{5} - \sqrt{3}$
គ. $\sqrt{11 + 2\sqrt{30}}$ $= \sqrt{(\sqrt{6}+\sqrt{5})^2} = \sqrt{6} + \sqrt{5}$
ឃ. $\sqrt{9 - 4\sqrt{5}}$ $= \sqrt{9 - 2\sqrt{20}} = \sqrt{5} - 2$
លំហាត់ទី ១៦. គណនាតម្លៃនៃកន្សោមបន្សាបរ៉ាឌីកាល់ខាងក្រោម៖ ខ្ពស់ • ៤ សំណួរ
ក. $P = \sqrt{4 + 2\sqrt{3}} - \sqrt{4 - 2\sqrt{3}}$ $= (\sqrt{3}+1) - (\sqrt{3}-1) = 2$
ខ. $Q = \sqrt{6 + 2\sqrt{5}} + \sqrt{6 - 2\sqrt{5}}$ $= (\sqrt{5}+1) + (\sqrt{5}-1) = 2\sqrt{5}$
គ. $R = \sqrt{(2-\sqrt{5})^2} + \sqrt{(3-\sqrt{5})^2}$ $= (\sqrt{5}-2) + (3-\sqrt{5}) = 1$
ឃ. $S = \sqrt{3 + \sqrt{5}} \cdot \sqrt{3 - \sqrt{5}}$ $= \sqrt{9 - 5} = \sqrt{4} = 2$
លំហាត់ទី ១៧. សម្រួលកន្សោមរ៉ាឌីកាល់មានអថេរ (អនុវត្តរូបមន្ត $\sqrt{A^2} = |A|$)៖ ខ្ពស់ • ៤ សំណួរ
ក. $\sqrt{9x^2}$ ចំពោះ $x < 0$ $= 3|x| = -3x$
ខ. $\sqrt{16x^4 y^2}$ ចំពោះ $y \ge 0$ $= 4x^2 |y| = 4x^2 y$
គ. $\sqrt{x^2 - 6x + 9}$ ($x \ge 3$ និង $x < 3$) $= x - 3$ (បើ $x \ge 3$) ; $3 - x$ (បើ $x < 3$)
ឃ. $\dfrac{\sqrt{a^3 b}}{\sqrt{ab}}$ ចំពោះ $a > 0, b > 0$ $= \sqrt{a^2} = a$
លំហាត់ទី ១៨. គណនាតម្លៃនៃផលបូកបំបាត់រ៉ាឌីកាល់បន្តបន្ទាប់ (Telescoping Sum)៖ ខ្ពស់ • សំណួរគន្លឹះ
$$S = \frac{1}{1 + \sqrt{2}} + \frac{1}{\sqrt{2} + \sqrt{3}} + \frac{1}{\sqrt{3} + \sqrt{4}} + \dots + \frac{1}{\sqrt{99} + \sqrt{100}}$$
$\to$ ដោយគុណកន្សោមឆ្លាស់ $\dfrac{1}{\sqrt{n}+\sqrt{n+1}} = \sqrt{n+1} - \sqrt{n}$ នាំឱ្យ $S = (\sqrt{2}-1) + (\sqrt{3}-\sqrt{2}) + \dots + (\sqrt{100}-\sqrt{99}) = \sqrt{100} - 1 = 10 - 1 = \mathbf{9}$
លំហាត់ទី ១៩. រកតម្លៃ $x$ ពីសមីការរ៉ាឌីកាល់កម្រិតខ្ពស់៖ ខ្ពស់ • ៤ សំណួរ
ក. $\sqrt{x^2 - 4x + 4} = 3$ $\to |x-2|=3 \implies x = 5$ ឬ $x = -1$
ខ. $\sqrt{2x - 1} = x - 2$ $\to x = 5$ (លក្ខខណ្ឌ $x \ge 2$, ចោល $x=1$)
គ. $x^2 - 2\sqrt{3}x + 2 = 0$ $\to (x-\sqrt{3})^2 = 1 \implies x = \sqrt{3} \pm 1$
ឃ. សម្រួល $\sqrt{x + 2\sqrt{x-1}} + \sqrt{x - 2\sqrt{x-1}}$ ($x \ge 2$) $= (\sqrt{x-1}+1) + (\sqrt{x-1}-1) = 2\sqrt{x-1}$

ក. ត្រីកោណកែងមានជ្រុងកែង $a=6\text{ cm}, b=8\text{ cm}$។ រកអ៊ីប៉ូតេនុស $c$។ $\to c = \sqrt{6^2+8^2} = \sqrt{100} = 10\text{ cm}$
ខ. ការេមានផ្ទៃ $S = 72\text{ cm}^2$។ រករង្វាស់ជ្រុង $a$ និងអង្កត់ទ្រូង $d$។ $\to a = \sqrt{72} = 6\sqrt{2}\text{ cm}$, $d = 12\text{ cm}$
គ. បន្ទប់រាងចតុកោណកែងមានបណ្តោយ $2\times$ ទទឹង និងផ្ទៃ $98\text{ m}^2$។ រកវិមាត្រ។ $\to 2x^2=98 \implies \text{ទទឹង } 7\text{ m}, \text{បណ្តោយ } 14\text{ m}$
ឃ. បង្ហាញថា $M = \sqrt{5+2\sqrt{6}} + \sqrt{5-2\sqrt{6}}$ មាន $M^2 = 12$ រួចទាញរក $M$។ $\to M^2 = 10 + 2 = 12 \implies M = \sqrt{12} = 2\sqrt{3}$
