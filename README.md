# 🎓 CVN App — ប្រព័ន្ធបង្រៀនគណិតវិទ្យាឌីជីថល

**CVN App** ជាប្រព័ន្ធបង្រៀនគណិតវិទ្យាឌីជីថលពេញលេញ (Interactive Math Education Platform) ដែលត្រូវបានបង្កើតសម្រាប់សិស្សថ្នាក់ទី ៩ ដល់ ១១ ក្នុងប្រព័ន្ធអប់រំកម្ពុជា។

## 📚 មុខងារសំខាន់ (Key Features)

- **📖 ឯកសារបង្រៀន** — Lesson Plans ជាទ្រង់ទ្រាយ IBL 5E Model
- **🧮 ល្បែងគណិតវិទ្យា** — Interactive Math Games ជំហានដោយជំហាន
- **📊 ក្រាបឌីជីថល** — Real-Time Graph Visualizer (y = aˣ, y = log, ...)
- **📝 លំហាត់** — IBL Inquiry Worksheets ជាក់ស្ដែង
- **🎓 ប្រឡង** — Mock Exams and Quizzes
- **⬇️ ទាញយក** — Export ជា PDF, Word, PowerPoint, Image
