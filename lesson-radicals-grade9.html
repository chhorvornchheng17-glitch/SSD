⚔️ កម្មវិធីសិក្សាគណិតវិទ្យា ថ្នាក់ទី ៩ ក្រសួងអប់រំ យុវជន និងកីឡា

មេរៀនទី ១៖ ប្រមាណវិធីលើរ៉ាឌីកាល់សន្ទស្សន៍ ២ និង ៣
ឫសការេ, ឫសគូប, វិធីគុណ និងវិធីចែករ៉ាឌីកាល់

ចងក្រងតាមសៀវភៅគោលក្រសួងអប់រំ យុវជន និងកីឡា (ទំព័រ ១-៥) ដោយរួមបញ្ចូលនូវ ១. ខ្លឹមសារមេរៀនពេញលេញ, ២. លំហាត់គំរូនិងដំណោះស្រាយលម្អិត, ៣. ប្រតិបត្តិអនុវត្តក្នុងថ្នាក់, និង ៤. កិច្ចការផ្ទះសមល្មម ឆ្លើយតបនឹងការវាស់ស្ទង់សមត្ថភាពសិស្ស។

🎯 វត្ថុបំណងចម្បងនៃមេរៀន (Learning Objectives)៖
១. រកឫសការេនៃមួយចំនួន និងដោះស្រាយសមីការ $x^2 = a$។
២. រកឫសគូបនៃមួយចំនួន និងដោះស្រាយសមីការ $x^3 = a$។
៣. ធ្វើប្រមាណវិធីគុណ និងចែកលើចំនួនអសនិទាន/រ៉ាឌីកាល់សន្ទស្សន៍ ២ និង ៣។
🖥️ បញ្ចាំងស្លាយបង្រៀន (Slides Deck) 🎮 លេង Math Hero ថ្នាក់ទី ៩

ផ្នែកទី ១៖ ខ្លឹមសារមេរៀនគន្លឹះ (Theory & Concepts)

សៀវភៅគោលទំព័រ ១-៥

១ ឫសការេ (Square Root)

📌 រំលឹកពីចំនួនសនិទាន៖
  • ដោះស្រាយសមីការ $x + 5 = 3 \implies x = 3 - 5 = -2$
  • ដោះស្រាយសមីការ $2x = 5 \implies x = \frac{5}{2} = 2.5$

ចំនួន $-2$, $\frac{5}{2}$, $2.5$ ហៅថា ចំនួនសនិទាន ($\mathbb{Q}$)។ ប៉ុន្តែមានករណីខ្លះ ចំនួនសនិទានពុំអាចបំពេញលក្ខខណ្ឌនៃសមីការបានឡើយ។

ឧទាហរណ៍ ១៖ រក $x$ ដែល $x^2 = 9$
ដោយ $3^2 = 9$ និង $(-3)^2 = 9$ នាំឱ្យ $x = 3$ ឬ $x = -3$។
គេថា $3$ និង $-3$ ជាឫសការេនៃ $9$។
ឧទាហរណ៍ ២៖ រក $x$ ដែល $x^2 = \frac{25}{4}$
ដោយ $\left(\frac{5}{2}\right)^2 = \frac{25}{4}$ និង $\left(-\frac{5}{2}\right)^2 = \frac{25}{4}$
គេបាន $\frac{25}{4}$ មានឫសការេពីរផ្ទុយគ្នាគឺ $\frac{5}{2}$ និង $-\frac{5}{2}$។
🔎 ឧទាហរណ៍ ៣ (ការកកើតចំនួនអសនិទាន)៖ រក $x$ ដែល $x^2 = 3$
  • បើឱ្យ $x = 1 \implies 1^2 = 1 < 3$
  • បើឱ្យ $x = \frac{3}{2} = 1.5 \implies (1.5)^2 = 2.25 < 3$
  • បើឱ្យ $x = \frac{5}{3} \approx 1.66 \implies \left(\frac{5}{3}\right)^2 = \frac{25}{9} \approx 2.77 < 3$
  • បើឱ្យ $x = 2 \implies 2^2 = 4 > 3$

យើងឃើញថា គ្មានចំនួនសនិទានណាដែលការេរបស់វាស្មើនឹង $3$ ឡើយ! ក្នុងករណីនេះ គេសន្មតតាង $\sqrt{3}$ ជាចំនួនមួយដែល $(\sqrt{3})^2 = 3$។
ចំនួន $\sqrt{3} \approx 1.7320...$ ហៅថា ចំនួនអសនិទាន។ ឫសការេនៃ $3$ គឺ $\sqrt{3}$ (ឫសការេវិជ្ជមាន) និង $-\sqrt{3}$ (ឫសការេអវិជ្ជមាន)។

⚠️ ឧទាហរណ៍ ៤ (លក្ខខណ្ឌឫសការេ)៖ រក $x$ បើ $x^2 = -3$
គេដឹងថា គ្រប់ចំនួនពិត $x$ ការេរបស់វាជានិច្ចកាល $x^2 \ge 0$ គ្មានតម្លៃ $x$ ណាធ្វើឱ្យ $x^2 < 0$ ឡើយ។ ដូចនេះ ចំនួនអវិជ្ជមានគ្មានឫសការេទេក្នុងសំណុំចំនួនពិត។

✨ ជាទូទៅ៖ ឫសការេនៃចំនួនពិត

បើ $a > 0$ សមីការ $x^2 = a$ នាំឱ្យ $x = \sqrt{a}$ និង $x = -\sqrt{a}$

សញ្ញា $\sqrt{}$ ហៅថារ៉ាឌីកាល់មានសន្ទស្សន៍ $2$, ចំនួន $a$ ហៅថារ៉ាឌីកង់។ បើ $a = 0$ នាំឱ្យ $x = 0$។

២ ឫសគូប (Cube Root)

ឧទាហរណ៍ ១ (ចំនួនវិជ្ជមាន)៖ រក $x$ ដែល $x^3 = 64$
ដោយ $4^3 = 64$ និង $(-4)^3 = -64 \ne 64$ នាំឱ្យ $x = 4$។
គេថា $64$ មានឫសគូបតែមួយគត់គឺ $x = \sqrt[3]{64} = 4$។
ឧទាហរណ៍ ២ (ចំនួនអវិជ្ជមាន)៖ រក $x$ ដែល $x^3 = -27$
ដោយ $(-3)^3 = -27$ នាំឱ្យ $x = -3$។
គេថា $-27$ មានឫសគូបតែមួយគត់គឺ $x = \sqrt[3]{-27} = -3$។
💡 ការសង្កេតសំខាន់៖
  • គ្រប់ចំនួនពិត (វិជ្ជមាន អវិជ្ជមាន ឬសូន្យ) សុទ្ធតែមានឫសគូបតែមួយគត់ជានិច្ច!
  • ឫសគូបនៃចំនួនវិជ្ជមាន ជាចំនួនវិជ្ជមាន ($\sqrt[3]{a} > 0$ កាលណា $a > 0$)
  • ឫសគូបនៃចំនួនអវិជ្ជមាន ជាចំនួនអវិជ្ជមាន ($\sqrt[3]{-a} = -\sqrt[3]{a}$)
  • ចំពោះចំនួនដែលគ្មានតម្លៃគូបប្រាកដ ដូចជា $x^3 = 17$ នោះ $x = \sqrt[3]{17}$ ជាចំនួនអសនិទាន។

✨ ជាទូទៅ៖ ឫសគូបនៃចំនួនពិត

បើ $x^3 = a$ គេបាន $x = \sqrt[3]{a}$ ($a$ អាចវិជ្ជមាន, អវិជ្ជមាន ឬសូន្យ)

សញ្ញា $\sqrt[3]{}$ ជារ៉ាឌីកាល់ដែលមានសន្ទស្សន៍ស្មើ $3$ ហើយ $a$ ជារ៉ាឌីកង់។

៣ ប្រមាណវិធីលើរ៉ាឌីកាល់ (Operations on Radicals)

៣.១ វិធីគុណរ៉ាឌីកាល់ (Multiplication of Radicals)

ពិនិត្យការប្រៀបធៀប៖ $\sqrt{4} \times \sqrt{9} = 2 \times 3 = 6$ និង $\sqrt{4 \times 9} = \sqrt{36} = 6 \implies \sqrt{4} \times \sqrt{9} = \sqrt{4 \times 9}$
$\sqrt[3]{8} \times \sqrt[3]{27} = 2 \times 3 = 6$ និង $\sqrt[3]{8 \times 27} = \sqrt[3]{216} = 6 \implies \sqrt[3]{8} \times \sqrt[3]{27} = \sqrt[3]{8 \times 27}$

រូបមន្តផលគុណរ៉ាឌីកាល់សន្ទស្សន៍ដូចគ្នា៖
$$\sqrt{a} \times \sqrt{b} = \sqrt{a \cdot b} \quad (a \ge 0, \; b \ge 0)$$ $$\sqrt[3]{a} \times \sqrt[3]{b} = \sqrt[3]{a \cdot b} \quad (a, b \in \mathbb{R})$$
«ផលគុណនៃរ៉ាឌីកាល់ដែលមានសន្ទស្សន៍ដូចគ្នា ស្មើនឹងរ៉ាឌីកាល់នៃផលគុណ»

៣.២ វិធីចែករ៉ាឌីកាល់ (Division of Radicals)

ពិនិត្យការប្រៀបធៀប៖ $\frac{\sqrt{36}}{\sqrt{4}} = \frac{6}{2} = 3$ និង $\sqrt{\frac{36}{4}} = \sqrt{9} = 3 \implies \frac{\sqrt{36}}{\sqrt{4}} = \sqrt{\frac{36}{4}}$
$\frac{\sqrt[3]{27}}{\sqrt[3]{8}} = \frac{3}{2}$ និង $\sqrt[3]{\frac{27}{8}} = \frac{3}{2} \implies \frac{\sqrt[3]{27}}{\sqrt[3]{8}} = \sqrt[3]{\frac{27}{8}}$

រូបមន្តផលចែករ៉ាឌីកាល់សន្ទស្សន៍ដូចគ្នា៖
$$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \quad (a \ge 0, \; b > 0)$$ $$\frac{\sqrt[3]{a}}{\sqrt[3]{b}} = \sqrt[3]{\frac{a}{b}} \quad (b \ne 0)$$
«ផលចែកនៃរ៉ាឌីកាល់ដែលមានសន្ទស្សន៍ដូចគ្នា ស្មើនឹងរ៉ាឌីកាល់នៃផលចែក»

ផ្នែកទី ២៖ លំហាត់គំរូ និងដំណោះស្រាយយ៉ាងក្បោះក្បាយ

៤ សំណុំលំហាត់គំរូពេញលេញ
លំហាត់គំរូទី ១៖ រកឫសនៃសមីការខាងក្រោម (ឫសការេ)៖
សៀវភៅគោល ទំព័រ ២
ក. $x^2 = 16$
ខ. $x^2 = 7$
គ. $x^2 = \frac{49}{9}$
ឃ. $x^2 = -81$
ង. $x^2 = 1$
ច. $x^2 = 0$
📝 ដំណោះស្រាយលម្អិត៖
  • ក. $4^2 = 16$ និង $(-4)^2 = 16$។ បើ $x^2 = 16$ ដូចនេះ $x = \sqrt{16} = 4$ ឬ $x = -\sqrt{16} = -4$។
  • ខ. ពុំមានចំនួនសនិទានណាដែលការេវាស្មើនឹង $7$ ទេ។ ដូចនេះឫសការេវាជាចំនួនអសនិទាន៖ $x = \sqrt{7}$ ឬ $x = -\sqrt{7}$។
  • គ. ដោយ $\left(\frac{7}{3}\right)^2 = \frac{49}{9}$ និង $\left(-\frac{7}{3}\right)^2 = \frac{49}{9}$ ដូចនេះ $x = \frac{7}{3}$ ឬ $x = -\frac{7}{3}$។
  • ឃ. គ្មានចំនួនពិតណាដែលការេវាជាចំនួនអវិជ្ជមានឡើយ ($x^2 \ge 0$ ជានិច្ច)។ ដូចនេះ $-81$ គ្មានឫសការេទេក្នុង $\mathbb{R}$។
  • ង. ដោយ $1^2 = 1$ និង $(-1)^2 = 1$ ដូចនេះ $x = \sqrt{1} = 1$ ឬ $x = -\sqrt{1} = -1$។
  • ច. ដោយ $0^2 = 0$ ដូចនេះ $x = 0$ ជាឫសការេតែមួយគត់នៃ $0$។
លំហាត់គំរូទី ២៖ រកឫសនៃសមីការខាងក្រោម (ឫសគូប)៖
សៀវភៅគោល ទំព័រ ៣-៤
ក. $x^3 = -64$
ខ. $x^3 = -1$
គ. $x^3 = 1$
ឃ. $x^3 = -8$
ង. $x^3 = 4$
ច. $x^3 = 0$
ឆ. $x^3 = \frac{1}{8}$
ជ. $x^3 = \frac{27}{125}$
ឈ. $x^3 = -\frac{1}{1000}$
📝 ដំណោះស្រាយលម្អិត៖
  • ក. $(-4)^3 = -64$ ដូចនេះ $x = \sqrt[3]{-64} = -4$
  • ខ. $(-1)^3 = -1$ ដូចនេះ $x = \sqrt[3]{-1} = -1$
  • គ. $1^3 = 1$ ដូចនេះ $x = \sqrt[3]{1} = 1$
  • ឃ. $(-2)^3 = -8$ ដូចនេះ $x = \sqrt[3]{-8} = -2$
  • ង. គ្មានចំនួនសនិទានណាដែលគូបវាស្មើនឹង $4$ ឡើយ។ ដូចនេះ $x = \sqrt[3]{4}$ (ជាចំនួនអសនិទាន)
  • ច. $0^3 = 0$ ដូចនេះ $x = 0$
  • ឆ. $\left(\frac{1}{2}\right)^3 = \frac{1}{8}$ ដូចនេះ $x = \sqrt[3]{\frac{1}{8}} = \frac{1}{2}$
  • ជ. $\left(\frac{3}{5}\right)^3 = \frac{27}{125}$ ដូចនេះ $x = \sqrt[3]{\frac{27}{125}} = \frac{3}{5}$
  • ឈ. $\left(-\frac{1}{10}\right)^3 = -\frac{1}{1000}$ ដូចនេះ $x = \sqrt[3]{-\frac{1}{1000}} = -\frac{1}{10}$
លំហាត់គំរូទី ៣៖ គណនាផលគុណនៃរ៉ាឌីកាល់ខាងក្រោម៖
សៀវភៅគោល ទំព័រ ៤
ក. $\sqrt{2} \times \sqrt{8}$
ខ. $\sqrt{3} \times \sqrt{27}$
គ. $\sqrt[3]{2} \times \sqrt[3]{4}$
ឃ. $\sqrt[3]{2} \times \sqrt[3]{\frac{1}{16}}$
ង. $\sqrt{2} \times \sqrt{32}$
ច. $\sqrt{50} \times \sqrt{2}$
📝 ដំណោះស្រាយលម្អិត៖
  • ក. $\sqrt{2} \times \sqrt{8} = \sqrt{2 \times 8} = \sqrt{16} = \sqrt{4^2} = 4$
  • ខ. $\sqrt{3} \times \sqrt{27} = \sqrt{3 \times 27} = \sqrt{81} = \sqrt{9^2} = 9$
  • គ. $\sqrt[3]{2} \times \sqrt[3]{4} = \sqrt[3]{2 \times 4} = \sqrt[3]{8} = \sqrt[3]{2^3} = 2$
  • ឃ. $\sqrt[3]{2} \times \sqrt[3]{\frac{1}{16}} = \sqrt[3]{2 \times \frac{1}{16}} = \sqrt[3]{\frac{1}{8}} = \sqrt[3]{\left(\frac{1}{2}\right)^3} = \frac{1}{2}$
  • ង. $\sqrt{2} \times \sqrt{32} = \sqrt{2 \times 32} = \sqrt{64} = \sqrt{8^2} = 8$
  • ច. $\sqrt{50} \times \sqrt{2} = \sqrt{50 \times 2} = \sqrt{100} = \sqrt{10^2} = 10$
លំហាត់គំរូទី ៤៖ គណនាផលចែកនៃរ៉ាឌីកាល់ខាងក្រោម៖
សៀវភៅគោល ទំព័រ ៥
ក. $\frac{\sqrt{8}}{\sqrt{2}}$
ខ. $\frac{\sqrt[3]{48}}{\sqrt[3]{6}}$
គ. $\frac{\sqrt{3}}{\sqrt{27}}$
ឃ. $\frac{\sqrt{288}}{\sqrt{2}}$
ង. $\frac{\sqrt[3]{16}}{\sqrt[3]{2}}$
ច. $\frac{\sqrt[3]{1/2}}{\sqrt[3]{4}}$
ឆ. $\frac{\sqrt{10}}{\sqrt{0.1}}$
ជ. $\frac{\sqrt[3]{25}}{\sqrt[3]{0.2}}$
📝 ដំណោះស្រាយលម្អិត៖
  • ក. $\frac{\sqrt{8}}{\sqrt{2}} = \sqrt{\frac{8}{2}} = \sqrt{4} = \sqrt{2^2} = 2$
  • ខ. $\frac{\sqrt[3]{48}}{\sqrt[3]{6}} = \sqrt[3]{\frac{48}{6}} = \sqrt[3]{8} = \sqrt[3]{2^3} = 2$
  • គ. $\frac{\sqrt{3}}{\sqrt{27}} = \sqrt{\frac{3}{27}} = \sqrt{\frac{1}{9}} = \sqrt{\left(\frac{1}{3}\right)^2} = \frac{1}{3}$
  • ឃ. $\frac{\sqrt{288}}{\sqrt{2}} = \sqrt{\frac{288}{2}} = \sqrt{144} = \sqrt{12^2} = 12$
  • ង. $\frac{\sqrt[3]{16}}{\sqrt[3]{2}} = \sqrt[3]{\frac{16}{2}} = \sqrt[3]{8} = \sqrt[3]{2^3} = 2$
  • ច. $\frac{\sqrt[3]{1/2}}{\sqrt[3]{4}} = \sqrt[3]{\frac{1/2}{4}} = \sqrt[3]{\frac{1}{8}} = \sqrt[3]{\left(\frac{1}{2}\right)^3} = \frac{1}{2}$
  • ឆ. $\frac{\sqrt{10}}{\sqrt{0.1}} = \sqrt{\frac{10}{0.1}} = \sqrt{100} = \sqrt{10^2} = 10$
  • ជ. $\frac{\sqrt[3]{25}}{\sqrt[3]{0.2}} = \sqrt[3]{\frac{25}{0.2}} = \sqrt[3]{125} = \sqrt[3]{5^3} = 5$

ផ្នែកទី ៣៖ ប្រតិបត្តិសម្រាប់សិស្សអនុវត្តក្នុងថ្នាក់រៀន

ប្រតិបត្តិ ១៖ រកឫសការេនៃចំនួនខាងក្រោម
ក. $0.04$
ខ. $0.01$
គ. $5$
ឃ. $-1$
ង. $\frac{25}{36}$
ច. $0.1$
💡 ចម្លើយត្រឹមត្រូវ៖
ក. $\pm\sqrt{0.04} = \mathbf{\pm 0.2}$
ខ. $\pm\sqrt{0.01} = \mathbf{\pm 0.1}$
គ. $\mathbf{\sqrt{5}}$ និង $\mathbf{-\sqrt{5}}$
ឃ. គ្មានឫសការេទេ ($-1 < 0$)
ង. $\pm\sqrt{\frac{25}{36}} = \mathbf{\pm \frac{5}{6}}$
ច. $\mathbf{\sqrt{0.1}}$ និង $\mathbf{-\sqrt{0.1}}$
ប្រតិបត្តិ ២៖ រកឫសគូបនៃចំនួនខាងក្រោម
ក. $0.008$
ខ. $-0.001$
គ. $0.08$
ឃ. $-0.4$
💡 ចម្លើយត្រឹមត្រូវ៖
ក. $\sqrt[3]{0.008} = \mathbf{0.2}$ (ព្រោះ $0.2^3 = 0.008$)
ខ. $\sqrt[3]{-0.001} = \mathbf{-0.1}$ (ព្រោះ $(-0.1)^3 = -0.001$)
គ. $\mathbf{\sqrt[3]{0.08}}$ (ចំនួនអសនិទាន)
ឃ. $\sqrt[3]{-0.4} = \mathbf{-\sqrt[3]{0.4}}$ (ចំនួនអសនិទាន)
ប្រតិបត្តិ ៣៖ គណនាផលគុណរ៉ាឌីកាល់
ក. $\sqrt{10} \times \sqrt{0.1}$
ខ. $\sqrt[3]{10} \times \sqrt[3]{0.1}$
💡 ចម្លើយត្រឹមត្រូវ៖
ក. $\sqrt{10} \times \sqrt{0.1} = \sqrt{10 \times 0.1} = \sqrt{1} = \mathbf{1}$
ខ. $\sqrt[3]{10} \times \sqrt[3]{0.1} = \sqrt[3]{10 \times 0.1} = \sqrt[3]{1} = \mathbf{1}$
ប្រតិបត្តិ ៤ (បន្ថែមពង្រឹង)៖ គណនាផលចែករ៉ាឌីកាល់
ក. $\frac{\sqrt{45}}{\sqrt{5}}$
ខ. $\frac{\sqrt[3]{54}}{\sqrt[3]{2}}$
💡 ចម្លើយត្រឹមត្រូវ៖
ក. $\frac{\sqrt{45}}{\sqrt{5}} = \sqrt{\frac{45}{5}} = \sqrt{9} = \mathbf{3}$
ខ. $\frac{\sqrt[3]{54}}{\sqrt[3]{2}} = \sqrt[3]{\frac{54}{2}} = \sqrt[3]{27} = \mathbf{3}$
