ជំពូកទី ១ ៖ ស្វីតចំនួនពិត

២. តួទី $n$ នៃស្វ៊ីតនព្វន្ត
ក. រូបមន្តទូទៅ $u_n = u_1 + (n - 1)d$ ខ. ផលសងរួម $d = u_n - u_{n-1}$
រយៈពេល ៖ ៥០ នាទី

I. វត្ថុបំណងនៃមេរៀន

  • វិជ្ជាសម្បទា (ចំណេះដឹង)៖ សិស្សកំណត់ និងចងចាំរូបមន្តតួទី $n$ នៃស្វ៊ីតនព្វន្ត $u_n = u_1 + (n - 1)d$ បានត្រឹមត្រូវច្បាស់លាស់តាមរយៈការពន្យល់ និងការទាញរកលំនាំជាមួយគ្រូ។
  • បំណិនសម្បទា (បំណិន)៖ សិស្សអនុវត្តរូបមន្តក្នុងការគណនាតួណាមួយនៃស្វ៊ីតនព្វន្ត រកផលសងរួម ($d$) និងរកតួទីមួយ ($u_1$) ក្នុងលំហាត់គំរូ និងលំហាត់ប្រតិបត្តិបានត្រឹមត្រូវដោយគ្មានកំហុស។
  • ចរិយាសម្បទា (ឥរិយាបថ)៖ បណ្តុះស្មារតីសិស្សឱ្យមានភាពក្លាហានក្នុងការដោះស្រាយបញ្ហាគណិតវិទ្យា មានការសហការគ្នាយ៉ាងសកម្មក្នុងក្រុម និងយកចិត្តទុកដាក់ខ្ពស់ក្នុងការរៀនសូត្រ។

II. សម្ភារឧបទេស

  • សម្រាប់គ្រូ៖ សៀវភៅពុម្ពគណិតវិទ្យាថ្នាក់ទី១១ ភាគ១ (ក្រសួងអប់រំ យុវជន និងកីឡា), បន្ទាត់វែង, ហ្វឺត/ដីសពណ៌, បន្ទះក្រដាសសំណួរ, កាតរូបមន្តសង្ខេប។
  • សម្រាប់សិស្ស៖ សៀវភៅពុម្ព, សៀវភៅសរសេរ, ប៊ិច, បន្ទាត់ និងក្តារឈ្នួន ឬសន្លឹកកិច្ចការ។

III. វិធីសាស្រ្តបង្រៀន

វិធីសាស្រ្តអនុវត្តតាមបែបសិស្សមជ្ឈមណ្ឌល (ការរិះរកលំនាំគំរូ, ការសួរសំណួរ-ចម្លើយ, ការពន្យល់ណែនាំរបស់គ្រូ និងការពិភាក្សាដោះស្រាយជាដៃគូ ឬក្រុមតូច)។

IV. ដំណើរការបង្រៀន

សកម្មភាពគ្រូ ខ្លឹមសារមេរៀន សកម្មភាពសិស្ស
ជំហានទី ១ ៖ រដ្ឋបាលថ្នាក់ (២ នាទី)
• ពិនិត្យអនាម័យ សណ្តាប់ធ្នាប់ក្នុងថ្នាក់រៀន
• ពិនិត្យវត្តមានសិស្ស
• ពង្រឹងស្មារតី និងជំរុញទឹកចិត្តសិស្សមុនចូលរៀន 		រដ្ឋបាលថ្នាក់ ៖
អវត្តមាន ៖ .......... នាក់, ស្រី .......... នាក់
បរិយាកាសថ្នាក់រៀនស្អាតបាត និងមានរបៀបរៀបរយ 		• ប្រធានថ្នាក់ក្រោកឈររាយការណ៍វត្តមាន
• សិស្សទាំងអស់អង្គុយស្ងប់ស្ងាត់ មានរបៀបរៀបរយ និងត្រៀមសម្ភារសិក្សា
ជំហានទី ២ ៖ រំលឹកមេរៀនចាស់ និងត្រួតពិនិត្យកិច្ចការផ្ទះ (៥ នាទី)
• ដាក់សំណួររំលឹកមេរៀន ៖
  ១. តើអ្វីជាស្វ៊ីតនព្វន្ត?
  ២. ចូររកផលសងរួម $d$ នៃស្វ៊ីត ៖ $3, 7, 11, 15, \dots$
• ហៅសិស្ស ១-២ នាក់ឡើងឆ្លើយ
• ត្រួតពិនិត្យ និងកែកិច្ចការផ្ទះដែលបានដាក់ពីម៉ោងមុន 		សំណួររំលឹក ៖
១. ស្វ៊ីតនព្វន្ត គឺជាស្វ៊ីតនៃចំនួនដែលតូនីមួយៗ (ចាប់ពីតួទី២) ស្មើនឹងតូមុនបន្ទាប់បូកនឹងចំនួនថេរ $d$ មួយ ហៅថា ផលសងរួម ៖
$$u_{n+1} = u_n + d \quad (\forall n \ge 1)$$ ២. ផលសងរួម ៖
$$d = 7 - 3 = 11 - 7 = 4$$ 		• សិស្សគិត ពិចារណា និងស្ម័គ្រចិត្តឡើងឆ្លើយសំណួរ
• សិស្សឯទៀតស្តាប់ និងផ្ទៀងផ្ទាត់ចម្លើយ
• សិស្សបើកសៀវភៅកិច្ចការផ្ទះឱ្យគ្រូពិនិត្យ និងផ្ទៀងកែ
ជំហានទី ៣ ៖ ដំណើរការបង្រៀន និងរៀន / មេរៀនថ្មី (៣៣ នាទី)
• សរសេរចំណងជើងមេរៀនលើក្តារខៀន

១. ការទាញរកទម្រង់ទូទៅ (១០ នាទី)
• ណែនាំសិស្សឱ្យពិនិត្យមើលលំនាំនៃស្វ៊ីតនព្វន្ត ៖
  - តួទីមួយ ៖ $u_1$
  - តួទីពីរ ៖ $u_2 = u_1 + d$
  - តួទីបី ៖ $u_3 = u_2 + d = u_1 + 2d$
  - តួទីបួន ៖ $u_4 = u_3 + d = u_1 + 3d$
• សួរសំណួរគន្លឹះ ៖ «ប្រសិនបើយើងចង់រកតួទី $n$ ($u_n$) តើមេគុណនៃ $d$ ស្មើនឹងប៉ុន្មាន?»
• ធ្វើសំយោគ និងសរសេររូបមន្តក្នុងប្រអប់

២. ឧទាហរណ៍គំរូ (១៣ នាទី)
• ដាក់ឧទាហរណ៍ទី ១ ៖
គេមានស្វ៊ីតនព្វន្ត $2, 7, 12, 17, \dots$
ក. កំណត់តួទីមួយ $u_1$ និងផលសងរួម $d$
ខ. រកកន្សោមតួទី $n$ ($u_n$)
គ. គណនាតួទី $20$ ($u_{20}$)
• ណែនាំ និងពន្យល់ជំហានដោះស្រាយ

• ដាក់ឧទាហរណ៍ទី ២ ៖
គេមានស្វ៊ីតនព្វន្តមួយដែលមានតួទី $5$ គឺ $u_5 = 19$ និងតួទី $10$ គឺ $u_{10} = 39$។ ចូររកផលសងរួម $d$ និងតួទីមួយ $u_1$។
• បង្ហាញរូបមន្តទូទៅបន្ថែម ៖ $u_n = u_p + (n - p)d$

៣. លំហាត់ប្រតិបត្តិ (១០ នាទី)
• ដាក់លំហាត់ប្រតិបត្តិឱ្យសិស្សពិភាក្សាជាដៃគូ ឬក្រុមតូច ៖
«គេឱ្យស្វ៊ីតនព្វន្ត $5, 9, 13, 17, \dots$ ចូរគណនាតួទី $15$ ($u_{15}$) និងតួទី $50$ ($u_{50}$)»
• ដើរសម្របសម្រួល និងជួយសិស្សដែលជួបការលំបាក
មេរៀន ៖ តួទី $n$ នៃស្វ៊ីតនព្វន្ត
ក. រូបមន្តទូទៅ ៖
បើ $(u_n)$ ជាស្វ៊ីតនព្វន្តដែលមានតួទីមួយ $u_1$ និងផលសងរួម $d$ នោះតួទី $n$ កំណត់ដោយ ៖
រូបមន្តតួទី $n$ នៃស្វ៊ីតនព្វន្ត
$$u_n = u_1 + (n - 1)d$$
* កំណត់សម្គាល់ ៖ បើស្គាល់តួទី $p$ នោះ $u_n = u_p + (n - p)d$

ខ. ឧទាហរណ៍គំរូ ៖
ឧទាហរណ៍ ១ ៖
ក. តួទីមួយ $u_1 = 2$, ផលសងរួម $d = 7 - 2 = 5$
ខ. រកកន្សោម $u_n$ ៖
តាមរូបមន្ត $u_n = u_1 + (n - 1)d$
$\Rightarrow u_n = 2 + (n - 1) \times 5$
$\Rightarrow u_n = 2 + 5n - 5 = 5n - 3$
គ. គណនា $u_{20}$ ៖
$\Rightarrow u_{20} = 5(20) - 3 = 100 - 3 = 97$

ឧទាហរណ៍ ២ ៖
តាមរូបមន្ត $u_n = u_p + (n - p)d$
$\Rightarrow u_{10} = u_5 + (10 - 5)d$
$\Rightarrow 39 = 19 + 5d$
$\Rightarrow 5d = 39 - 19 = 20 \Rightarrow d = 4$
រកតួទីមួយ $u_1$ ៖
$u_5 = u_1 + 4d \Rightarrow 19 = u_1 + 4(4)$
$\Rightarrow u_1 = 19 - 16 = 3$
ដូចនេះ $u_1 = 3$ និង $d = 4$។

គ. ប្រតិបត្តិ ៖
ស្វ៊ីត $5, 9, 13, 17, \dots$
• $u_1 = 5$, ផលសងរួម $d = 9 - 5 = 4$
• $u_{15} = 5 + (15 - 1) \times 4 = 5 + 14 \times 4 = 5 + 56 = 61$
• $u_{50} = 5 + (50 - 1) \times 4 = 5 + 49 \times 4 = 5 + 196 = 201$ 		• សិស្សកត់ត្រាចំណងជើងមេរៀនចូលក្នុងសៀវភៅ

• សិស្សសង្កេត និងវិភាគលំនាំមេគុណនៃ $d$ (តួទី២ មាន $1d$, តួទី៣ មាន $2d$, តួទី៤ មាន $3d$)

• សិស្សឆ្លើយ ៖ «មេគុណនៃ $d$ គឺ $(n-1)$ ព្រោះវាតូចជាងលំដាប់តួចំនួន ១!»
• សិស្សទន្ទេញ និងកត់ត្រារូបមន្តចូលក្នុងសៀវភៅ


• សិស្សចូលរួមឆ្លើយតាមការណែនាំរបស់គ្រូ

• សិស្សកត់ត្រាឧទាហរណ៍ និងរបៀបដោះស្រាយចូលក្នុងសៀវភៅ



• សិស្សស្ម័គ្រចិត្តម្នាក់ឡើងដោះស្រាយលើក្តារខៀន
• សិស្សឯទៀតផ្ទៀងផ្ទាត់ដំណោះស្រាយ




• សិស្សធ្វើការជាដៃគូ ឬក្រុមតូច គិតលេខលើក្តារឈ្នួន ឬសៀវភៅព្រាង
• តំណាងសិស្សឡើងធ្វើបង្ហាញលើក្តារខៀន
ជំហានទី ៤ ៖ ពង្រឹងពុទ្ធិ / ពង្រឹងចំណេះដឹង (៧ នាទី)
• ដាក់លំហាត់ខ្លីដើម្បីវាស់ស្ទង់ការយល់ដឹងរបស់សិស្ស ៖
«គេមានស្វ៊ីតនព្វន្តមួយមាន $u_1 = -3$ និង $d = 2$។ ចូររកតួទី $11$ ($u_{11}$)។»
• ហៅសិស្សកម្រិតមធ្យម ឬសិស្សរៀនយឺតឡើងគណនាលើក្តារខៀន
• សម្របសម្រួល កែតម្រូវ និងផ្តល់ការលើកទឹកចិត្ត 		លំហាត់ពង្រឹងចំណេះដឹង ៖
គណនា $u_{11}$ ៖
តាមរូបមន្ត $u_n = u_1 + (n - 1)d$
$u_{11} = -3 + (11 - 1) \times 2$
$u_{11} = -3 + 10 \times 2 = -3 + 20 = 17$
ដូចនេះ $u_{11} = 17$ 		• សិស្សទាំងអស់គិត និងគណនាក្នុងសៀវភៅព្រាងយ៉ាងសកម្ម
• សិស្សដែលគ្រូហៅឡើងធ្វើបង្ហាញលើក្តារខៀន
• សិស្សឯទៀតផ្ទៀងផ្ទាត់ចម្លើយ និងកែតម្រូវបើមានខុស
ជំហានទី ៥ ៖ បណ្តាំផ្ញើ និងកិច្ចការផ្ទះ (៣ នាទី)
• ផ្តាំផ្ញើសិស្សឱ្យទន្ទេញរូបមន្តតួទី $n$ នៃស្វ៊ីតនព្វន្តឱ្យចាំច្បាស់
• ដាក់កិច្ចការផ្ទះ ៖
  ១. រកតួទី $30$ នៃស្វ៊ីតនព្វន្ត ៖ $1, 6, 11, 16, \dots$
  ២. រកតួទីមួយ $u_1$ និង $d$ បើគេដឹងថា $u_3 = 8$ និង $u_8 = 23$
• រំលឹកឱ្យសិស្សមើលមេរៀនបន្ទាប់ ៖ «ផលបូក $n$ តួដំបូងនៃស្វ៊ីតនព្វន្ត ($S_n$)» 		កិច្ចការផ្ទះ ៖
១. គណនា $u_{30}$ នៃស្វ៊ីត $1, 6, 11, 16, \dots$
២. រក $u_1$ និង $d$ បើ $u_3 = 8$ និង $u_8 = 23$
៣. អានស្វ័យសិក្សាទុកជាមុន ៖ ផលបូក $n$ តួដំបូងនៃស្វ៊ីតនព្វន្ត ($S_n$) 		• ទទួល និងកត់ត្រាកិច្ចការផ្ទះចូលក្នុងសៀវភៅ
• សម្អាតក្តារខៀន និងរៀបចំសម្ភារត្រៀមសម្រាប់ម៉ោងសិក្សាបន្ទាប់

V. ប្លង់ក្តារខៀន

ប្លង់ក្តារខៀន៖ ស្វ៊ីតនព្វន្ត (តួទី n នៃស្វ៊ីតនព្វន្ត)
ផ្ទាំងទី ១៖ រំលឹក & រូបមន្តទូទៅ

១. រំលឹក៖

• ស្វ៊ីតនព្វន្ត ៖ $u_{n+1} = u_n + d$

• ផលសងរួម ៖ $d = u_{n+1} - u_n$

២. រូបមន្តតួទី $n$៖

$u_n = u_1 + (n - 1)d$

• $u_1$ ៖ តួទីមួយ

• $d$ ៖ ផលសងរួម

• $n$ ៖ លំដាប់តួ ($n \in \mathbb{N}$)

• រូបមន្តពន្លាត៖ $u_n = u_p + (n - p)d$

[ទ្រឹស្តី និងរូបមន្តគ្រឹះ]
ផ្ទាំងទី ២៖ ឧទាហរណ៍គំរូ

៣. ឧទាហរណ៍ ១៖

• ស្វ៊ីត ៖ $2, 7, 12, 17, \dots$

• $u_1 = 2$, $d = 7 - 2 = 5$

• $u_n = 2 + 5(n - 1) = 5n - 3$

• $u_{20} = 5(20) - 3 = 97$

៤. ឧទាហរណ៍ ២៖

• $u_5 = 19$, $u_{10} = 39$

• $39 = 19 + 5d \Rightarrow d = 4$

• $19 = u_1 + 4(4) \Rightarrow u_1 = 3$

[វិធីសាស្ត្រគណនា]
ផ្ទាំងទី ៣៖ ប្រតិបត្តិ & កិច្ចការផ្ទះ

៥. ប្រតិបត្តិ៖

• ស្វ៊ីត ៖ $5, 9, 13, 17, \dots$

• $u_1 = 5$, $d = 4$

• $u_{15} = 5 + 14(4) = 61$

• $u_{50} = 5 + 49(4) = 201$

៦. ពង្រឹង៖ $u_{11} = -3 + 10(2) = 17$

៧. កិច្ចការផ្ទះ៖

• រក $u_{30}$ នៃ $1, 6, 11, \dots$

• រក $u_1, d$ បើ $u_3=8, u_8=23$

[អនុវត្ត & បណ្តាំផ្ញើ]

VI. ឧបសម្ព័ន្ធ៖ សន្លឹកកិច្ចការប្រតិបត្តិរបស់សិស្ស

សន្លឹកកិច្ចការអនុវត្តគណិតវិទ្យា
មេរៀន៖ ស្វ៊ីតនព្វន្ត (ខ្លឹមសារ៖ តួទី n នៃស្វ៊ីតនព្វន្ត)
ឈ្មោះសិស្ស/ក្រុម៖ ................................. ថ្នាក់ទី៖ ១១ .........

សកម្មភាពអនុវត្ត ៖ ចូរគណនាតម្លៃនៃតួដែលចង់បានតាមតារាងខាងក្រោមដោយប្រើប្រាស់រូបមន្ត $u_n = u_1 + (n-1)d$៖

ស្វ៊ីតនព្វន្ត $(u_n)$ តួទីមួយ ($u_1$) ផលសងរួម ($d$) តួដែលត្រូវគណនា

ខ. $10, 6, 2, -2, \dots$ $10$ $-4$ $u_{15} = ................................$
គ. $u_1 = -5, d = 3$ $-5$ $3$ $u_{30} = ................................$

VII. យុទ្ធសាស្ត្រគាំទ្រសិស្សចម្រុះកម្រិត

🌱 សម្រាប់សិស្សរៀនយឺត៖
  • ណែនាំឱ្យសរសេរកំណត់ចំណាំធាតុ $u_1, d, n$ ឱ្យដាច់ដោយឡែកមុននឹងចាប់ផ្តើមជំនួសលេខចូលក្នុងរូបមន្ត។
  • ជួយពន្យល់ពីផលសង $d = u_2 - u_1$ ពិសេសករណីផលសងជាចំនួនអវិជ្ជមាន ($d < 0$)។
  • ផ្តល់តារាងលំនាំបូកបន្ថែមជាជំហានៗ ដើម្បីឱ្យសិស្សមើលឃើញរូបភាពច្បាស់។
🚀 សម្រាប់សិស្សពូកែ៖
  • ឱ្យសាកល្បងរកតួទីមួយ និងផលសងរួមតាមប្រព័ន្ធសមីការពីរអញ្ញាត ៖ $\begin{cases} u_3 + u_7 = 26 \\ u_2 + u_6 = 22 \end{cases}$។
  • ចោទសួរអំពីការរកចំនួនតួ $n$ នៅពេលស្គាល់តួចុងក្រោយ $u_n$ ៖ «តើស្វ៊ីត $3, 7, 11, \dots, 403$ មានប៉ុន្មានតួ?»
