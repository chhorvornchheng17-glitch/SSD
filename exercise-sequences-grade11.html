ថ្នាក់ទី១១ (ស្រង់ចេញពីសៀវភៅកិច្ចការផ្ទះ ២០២៦)

ប្រជុំលំហាត់អនុវត្តគ្រប់ប្រភេទពីមេរៀនទី១ «ស្វ៊ីតចំនួនពិត» (ទំព័រ ០១ ដល់ ២២ នៃសៀវភៅកិច្ចការផ្ទះ) រួមមាន៖ ការរកតួបន្តបន្ទាប់, ការសរសេរតួតគ្នានៃស្វ៊ីតរាប់អស់, ការកំណត់រូបមន្តតួទី $n$, ការសិក្សាភាពកើន-ចុះ និងម៉ូណូតូន, ព្រមទាំងការស្រាយបញ្ជាក់ស្វ៊ីតទាល់លើ ទាល់ក្រោម និងទាល់។

លំហាត់ទី ១. ចូរសរសេរបីតួបន្តទៀតនៃស្វ៊ីតខាងក្រោម៖ ៨ សំណួរ

លំហាត់ទី ២. ចូរសរសេរបីតួបន្តទៀតនៃស្វ៊ីតខាងក្រោម (លំនាំស្មុគស្មាញ)៖ ១០ សំណួរ
១. $3, 6, 11, 18, \dots$ $\to 27, 38, 51$ ($n^2+2$)

លំហាត់ទី ៣. ចូរសរសេរបីតួបន្តទៀតនៃស្វ៊ីតប្រភាគខាងក្រោម៖ ៤ សំណួរ

🔢 ផ្នែកទី ២៖ សរសេរតួតគ្នានៃស្វ៊ីតរាប់អស់ (Finite Sequences)
លំហាត់ទី ៤. សរសេរតួតគ្នានៃស្វ៊ីតរាប់អស់ខាងក្រោម៖ ៨ សំណួរ
១. $a_n = \dfrac{2n}{n+1}$ ចំពោះ $1 \le n \le 4$ $\to 1, \dfrac{4}{3}, \dfrac{3}{2}, \dfrac{8}{5}$
៥. $a_n = 2^{-n+2}$ ចំពោះ $1 \le n \le 5$ $\to 2, 1, \dfrac{1}{2}, \dfrac{1}{4}, \dfrac{1}{8}$
២. $w_n = n + \dfrac{1}{n^2}$ ចំពោះ $1 \le n \le 5$ $\to 2, \dfrac{9}{4}, \dfrac{28}{9}, \dfrac{65}{16}, \dfrac{126}{25}$
៦. $b_n = \dfrac{(-1)^{n+1}}{2n+1}$ ចំពោះ $0 \le n < 4$ $\to -1, \dfrac{1}{3}, -\dfrac{1}{5}, \dfrac{1}{7}$
៣. $a_n = 3 - \dfrac{1}{n^2}$ ចំពោះ $0 < n \le 4$ $\to 2, \dfrac{11}{4}, \dfrac{26}{9}, \dfrac{47}{16}$
៧. $v_n = (-1)^n(n+1)^2$ ចំពោះ $1 \le n < 6$ $\to -4, 9, -16, 25, -36$
៤. $a_n = \dfrac{(-1)^n}{n} + 2n$ ចំពោះ $1 \le n \le 5$ $\to 1, \dfrac{9}{2}, \dfrac{17}{3}, \dfrac{33}{4}, \dfrac{49}{5}$
៨. $a_n = \dfrac{n!}{2^n}$ ចំពោះ $1 \le n \le 4$ $\to \dfrac{1}{2}, \dfrac{1}{2}, \dfrac{3}{4}, \dfrac{3}{2}$
លំហាត់ទី ៥. សរសេរតួតគ្នានៃស្វ៊ីតរាប់អស់ (កន្សោមស្មុគស្មាញ)៖ ៧ សំណួរ
១. $a_n = \dfrac{2026\pi}{n}$ ចំពោះ $1 \le n \le 4$ $\to 2026\pi, 1013\pi, \dfrac{2026\pi}{3}, \dfrac{1013\pi}{2}$
៥. $a_n = (-1)^n + \cos(n\pi)$ ចំពោះ $1 \le n < 5$ $\to -2, 2, -2, 2$
២. $w_n = \dfrac{e^n}{n^2+3n-4}$ ចំពោះ $2 \le n \le 4$ $\to \dfrac{e^2}{6}, \dfrac{e^3}{14}, \dfrac{e^4}{24}$
៦. $b_n = \dfrac{(-1)^{n+1}}{n+1}$ ចំពោះ $1 \le n < 5$ $\to \dfrac{1}{2}, -\dfrac{1}{3}, \dfrac{1}{4}, -\dfrac{1}{5}$
៣. $a_n = \dfrac{n^3+2n^2-1}{n^2+1}$ ចំពោះ $2 \le n \le 5$ $\to 3, \dfrac{22}{5}, \dfrac{95}{17}, \dfrac{87}{13}$
៧. $v_n = (n\sqrt{n})^{n+1}$ ចំពោះ $1 \le n \le 4$ $\to 1, 16\sqrt{2}, 243\sqrt{3}, 32768$
៤. $a_n = \sqrt{n^2+1}-n$ ចំពោះ $0 \le n < 5$ $\to 1, \sqrt{2}-1, \sqrt{5}-2, \sqrt{10}-3, \sqrt{17}-4$
📐 ផ្នែកទី ៣៖ កំណត់រូបមន្តតួទី n ($a_n$) នៃស្វ៊ីត

៦. $(a_n): 2, 22, 222, 2222, \dots$ $\to a_n = \dfrac{2}{9}(10^n - 1)$
